# 安全策略

## 支持版本

| 版本 | 支持状态 |
| --- | --- |
| 2.0.x | 支持 |
| 1.x | 不再维护 |

## 报告安全问题

请**不要**在公开 Issue 中披露以下内容：

- 可直接利用的漏洞细节
- API Key、邮箱密码、DPAPI 密文
- 真实账号、客户数据、数据库文件
- 内部网络地址与拓扑

建议通过项目维护者的私下渠道报告，并附上：

1. 影响版本
2. 复现步骤
3. 影响范围
4. 建议修复方式（如有）
5. 脱敏后的日志或截图

## 本项目的安全边界

- 任务数据默认保存在本机：
  - 客户端：`%APPDATA%\TaskDock\data.json`
  - 服务端：`%APPDATA%\TaskDockServer\server.db`
- AI API Key 使用 Windows DPAPI 加密保存。
- 邮件密码优先使用 DPAPI；不可用时退化为本地编码，仅适用于受控终端。
- 管理端和客户端之间的 HTTP 默认不加密，适合内网或 VPN；跨公网必须使用 HTTPS 反向代理。
- 好友私聊仅在双方客户端可见，不进入管理端消息中心。
- 任务删除后消息中心仍保留历史对话，但为只读。

## 部署建议

1. 不要把 8787 端口直接暴露到公网。
2. 使用 Nginx / Caddy / IIS 做 HTTPS 反向代理。
3. 为管理端设置强密码，并限制管理端访问来源。
4. 定期备份 `server.db`，备份文件不要提交到 Git。
5. 客户端机器应启用磁盘加密和屏幕锁定。
6. 不在共享终端保存邮箱密码或 API Key。

## 密钥泄露处理

如果怀疑 API Key、邮箱密码或账户凭据泄露：

1. 立即在服务商控制台吊销/轮换密钥。
2. 修改邮箱密码。
3. 停用或重置相关账户。
4. 检查 `%APPDATA%`、日志、截图和 Git 历史是否包含敏感信息。
5. 必要时清理 Git 历史并重新发布。
